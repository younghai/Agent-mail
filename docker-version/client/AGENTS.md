# v0 Agent Inbox Working Rules

## Change Log Requirement

For every non-trivial source, UX, workflow, or operations change in this folder, create or update a dated Markdown file under `docs/change-logs/`.

Use this filename pattern:

`YYYY-MM-DD-<scope>-<summary>.md`

The file must include:

- Scope
- User journey or operational reason
- Applied changes
- Explicit non-changed areas
- Verification performed

## Version Scope

When the user asks to modify only `v0`, do not edit `v1-present`, `v1-new`, or sibling version folders.

When the user asks to modify only `v1-present`, do not edit `v0`, `v1-new`, or sibling version folders.
