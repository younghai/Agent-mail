# v0 Functional Requirements

## FR-01 이메일 수신

- **FR-01.1**: Cloudflare Email Routing을 통해 수신된 이메일을 파싱하여 INBOX에 저장
- **FR-01.2**: 수신 시 같은 스레드(Subject 기반 또는 In-Reply-To 기반)로 자동 그룹핑
- **FR-01.3**: 첨부파일은 R2에 저장하고 메타데이터는 DB에 기록
- **FR-01.4**: 수신 즉시 EmailAgent에 `/onNewEmail` 이벤트를 비동기로 발행

## FR-02 이메일 발신

- **FR-02.1**: 사용자가 UI에서 새 메일을 작성하여 발신 가능
- **FR-02.2**: Reply/Forward 기능 지원
- **FR-02.3**: 발신 시 SENT 폼더에 자동 저장
- **FR-02.4**: Rate limiting 적용 (발신 빈도 제한)

## FR-03 Draft 관리

- **FR-03.1**: 사용자가 수동으로 draft를 생성/수정/삭제 가능
- **FR-03.2**: AI 에이전트가 자동으로 생성한 draft를 별도로 관리
- **FR-03.3**: draft에서 이어서 발신 가능

## FR-04 AI 자동 답변 (핵심 기능)

- **FR-04.1**: 새 이메일 수신 시 AI가 자동으로 답변 초안을 생성
- **FR-04.2**: 스레드 전체 맥락을 고려하여 답변 작성
- **FR-04.3**: 프롬프트 인젝션 공격 시 자동으로 draft 생성 차단
- **FR-04.4**: 생성된 draft는 DRAFT 폼더에 저장되며, 사용자 검토 후 발송
- **FR-04.5**: AI는 절대 직접 이메일을 발송하지 않음 (Draft Only)

## FR-05 에이전트 채팅

- **FR-05.1**: 웹 UI에서 AI 에이전트와 실시간 채팅 가능 (스트리밍)
- **FR-05.2**: 채팅에서 이메일 목록 조회, 특정 메일 읽기, draft 작성 등의 명령 가능
- **FR-05.3**: 에이전트가 사용하는 도구: `list_emails`, `get_email`, `get_thread`, `search_emails`, `draft_reply`, `draft_email`, `mark_email_read`, `move_email`, `discard_draft`

## FR-06 메일박스 관리

- **FR-06.1**: 메일박스 CRUD (생성 시 R2에 설정 파일 자동 생성)
- **FR-06.2**: 메일박스별 시스템 프롬프트 커스터마이징 (R2에 JSON으로 저장)
- **FR-06.3**: 폼더 CRUD (기본 폼더는 삭제 불가)

## FR-07 검색 및 조회

- **FR-07.1**: 메일박스 내 이메일 목록 조회 (폼더별, 스레드별, 페이징)
- **FR-07.2**: 이메일 상세 조회 (본문, 헤더, 첨부파일)
- **FR-07.3**: 키워드 기반 이메일 검색
- **FR-07.4**: 스레드 단위로 이메일 묶어서 조회

## FR-08 보안

- **FR-08.1**: Production 환경에서 Cloudflare Access JWT 검증
- **FR-08.2**: Local dev 환경에서는 인증을 우회 (개발 편의성)
- **FR-08.3**: 프롬프트 인젝션 감지 및 차단
- **FR-08.4**: AI 생성 draft에 에이전트 메타 코멘터리가 포함되지 않도록 검증
