# Cost Guard + KV Dedup Persistence (2026-05-08)

## Part A — Cost Guard

### Changed Files
- `workers/lib/cost-guard/budget.ts` — new module: `recordAndCheck()`, `UsageStorage`, `BudgetEnv`, `CostCheckResult`
- `workers/admin/index.ts` — added `recordCostAndCheck(costUsd, budgetEnv)` method that adapts `DurableObject.ctx.storage` as `UsageStorage`
- `workers/agent/index.ts` — `recordAgentUsage()` accepts optional `estimatedCostUsd?`; calls `admin.recordCostAndCheck()` when cost > 0
- `workers/types.ts` — comment updated (DAILY_BUDGET_USD, MONTHLY_BUDGET_USD are auto-generated by cf-typegen from wrangler.jsonc)
- `wrangler.jsonc` — added `"DAILY_BUDGET_USD": "10"` and `"MONTHLY_BUDGET_USD": "200"` to `vars`

### Integration Point
`workers/agent/index.ts:recordAgentUsage` — after the existing `admin.recordAgentUsage` call, when `estimatedCostUsd > 0`:
1. Calls `admin.recordCostAndCheck(costUsd, { DAILY_BUDGET_USD, MONTHLY_BUDGET_USD })`
2. If `withinDailyBudget` or `withinMonthlyBudget` is false → calls `captureWorkerError(..., "fatal")`
3. Wrapped in try/catch — never blocks the agent flow

### Budget Behavior
- Limits: daily default $10, monthly default $200 (configurable via wrangler.jsonc vars)
- Storage keys: `cost:day:YYYY-MM-DD` and `cost:month:YYYY-MM` in Admin DO's durable storage
- **Alert only** — exceeding a limit triggers a fatal Slack alert but does NOT stop the agent

## Part B — Slack Alert KV Dedup Persistence

### Changed Files
- `workers/lib/observability/slack-alert.ts`:
  - Added `DedupStorage` interface
  - Added `memoryDedupStorage()` factory (in-memory Map, isolate-scoped)
  - Added `kvDedupStorage(kv, ttlMinutes)` factory (KV-backed, cross-isolate persistent)
  - `DefaultSlackAlertClient` now accepts optional `storage?: DedupStorage`; defaults to `memoryDedupStorage()`
  - `DefaultClientOptions` extended with optional `storage?: DedupStorage`
  - Added `AlertEnv` interface with `SLACK_DEDUP_KV?: KVNamespace`
  - `initSlackAlert(env: AlertEnv)` selects KV or memory storage based on `env.SLACK_DEDUP_KV`
- `wrangler.jsonc` — added `kv_namespaces` binding for `SLACK_DEDUP_KV` (id: `REPLACE_ON_DEPLOY`)
- `tests/slack-alert.test.ts` — all 8 existing `DefaultSlackAlertClient` instantiations updated to pass `storage: memoryDedupStorage()`; 5 new KV dedup tests added

### KV vs Memory Selection Logic
```
env.SLACK_DEDUP_KV present  →  kvDedupStorage(kv, ttlMinutes)
env.SLACK_DEDUP_KV absent   →  memoryDedupStorage()
```
KV keys are prefixed `slack-dedup:<fingerprint>` with TTL = `ttlMinutes * 60 + 60` seconds.
