# 00-Planning — Agent Mail (v1-present)

## 프로젝트 개요

Agent Mail은 `bzconnect.co`의 AI 기반 이메일 운영 마이크로서비스입니다. 수신 이메일에 대해 자동 분류, 요약, 초안 생성을 수행하며, 운영자의 승인을 거쳐 발송됩니다.

## 핵심 목표

1. **자동화**: 수신 이메일 → AI 초안 생성 → Drafts 폴리 저장 (최소 개입)
2. **통제**: 운영자가 초안을 검토·수정·승인할 수 있는 HITL 파이프라인
3. **확장성**: 고객사별 메일박스 격리, API 기반 외부 연동

## MVP 범위 (In)

- 메일박스 CRUD, 이메일/스레드/폴리 관리
- OpenAI 기반 초안 생성 및 SSE 챗
- 관리자 CRM (고객, 작업, 사용량 추적)
- PostgreSQL + Redis + MinIO 인프라

## Out of Scope (현재)

- 시각적 워크플로우 빌더 (v1-new로 이관)
- 다국어 자동 번역
- 실시간 협업 편집
- 모바일 네이티브 앱

## 이해관계자

| 역할 | 설명 |
|------|------|
| CSM / 영업팀 | 메일박스 설정, AI 초안 검수, 고객 관리 |
| 개발팀 | API 개발, AI 프롬프트 튜닝, 인프라 운영 |
| 관리자 | 대시보드 확인, 비용 모니터링, 계정 관리 |

## KPI

- AI 초안 생성 시간: < 5초 (P95)
- 초안 채택률: > 70%
- 메일 처리 지연: 수신 후 60초 내 초안 생성
