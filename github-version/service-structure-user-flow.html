localhost:5174 현재 상태

http://localhost:5174/는 현재 v1-present가 아니다. 실행 PID의 cwd는 v0/agent-inbox이며 React Router UI가 응답한다.

v1-present의 실제 성격

v1-present는 독립 프론트엔드가 아니라 Mail Server와 AI Agent 중심의 Docker 기반 마이크로서비스다.

현재 같이 떠 있는 서비스

localhost:5175는 v1-present-agentic-inbox UI, localhost:3000은 그 UI의 API 서버다.

3. 메일 수신 및 Agent 처리 흐름

sequenceDiagram
  participant Sender as External Sender
  participant Inbound as Webhook or SMTP Inbound
  participant Mail as Mail Server
  participant DB as PostgreSQL
  participant Storage as MinIO
  participant Redis as Redis Stream
  participant Agent as AI Agent
  participant LLM as OpenAI

  Sender->>Inbound: Send email
  Inbound->>Mail: POST /api/v1/webhooks/email or SMTP event
  Mail->>DB: Upsert mailbox, folder, email, thread metadata
  Mail->>Storage: Store attachments when present
  Mail->>Redis: XADD email-events new_email
  Agent->>Redis: XREADGROUP email-events
  Agent->>DB: Load email/thread context
  Agent->>LLM: Draft or chat request if key configured
  LLM-->>Agent: Generated draft
  Agent->>DB: Save draft candidate and AI usage
  Agent-->>Redis: Ack success or write DLQ on failure

5. 운영 서비스 흐름

stateDiagram-v2
  [*] --> NotStarted
  NotStarted --> Booting: docker compose up --build
  Booting --> InfraReady: postgres redis minio healthy
  InfraReady --> MailReady: mail-server /ready ok
  InfraReady --> AgentReady: ai-agent /ready ok
  MailReady --> ServiceReady
  AgentReady --> ServiceReady
  ServiceReady --> Degraded: AI key missing or Redis/DB unavailable
  Degraded --> ServiceReady: config fixed and health restored
  ServiceReady --> ProcessingEmail: inbound email or user request
  ProcessingEmail --> DraftReady: AI draft saved
  ProcessingEmail --> DLQ: retry exhausted or provider failure
  DLQ --> ProcessingEmail: operator retry
  DraftReady --> [*]

7. 판단

http://localhost:5174/가 브라우저에서 보이는 화면은 현재 /Users/young/Downloads/personal_project/using mail_AI/v1-present 자체가 아니다. 현재 5174는 v0/agent-inbox UI다.

v1-present는 메일/AI 기능을 제공하는 API 서비스 계층이며, 실제 사용자 화면은 별도 프론트엔드가 붙어야 완성된다. 따라서 “v1-present를 5174에서 보고 있다”라고 표현하면 정확하지 않고, “5174의 v0 UI가 v1-present 계열 API와 연결될 수 있다”가 더 정확하다.
